## ✏️ របៀបកែប្រែមេរៀន

### កែ Content មេរៀន

1. បើក file `topics/XX.js` (ឧ. `topics/01.js`)
2. កែប្រែ content ក្នុង `content` property

```javascript
const TOPIC_01 = {
    id: 1,
    title: "កុំផ្លិច",
    icon: "🔢",
    iconPath: "icons/01.png",
    tag: "មេរៀនទី១",
    semester: 1,
    description: "ពិពណ៌នាថ្មី...",
    pdfs: [
        { name: "file.pdf", path: "pdfs/01_កុំផ្លិច/lession/file.pdf", type: "lesson" }
    ],
    content: `
        <h3>១. និយមន័យ</h3>
        <p>មាតិកាមេរៀនថ្មី...</p>
        <div class="formula-box">
            $$x^2 + y^2 = r^2$$
        </div>
    `
};
```

### បន្ថែម PDF ថ្មី

1. ដាក់ PDF ក្នុង folder `pdfs/XX_ឈ្មោះប្រធានបទ/`
2. បន្ថែម info ក្នុង `pdfs` array

```javascript
pdfs: [
    { name: "ឈ្មោះ.pdf", path: "pdfs/01_កុំផ្លិច/lession/ឈ្មោះ.pdf", type: "lesson" },
    { name: "លំហាត់.pdf", path: "pdfs/01_កុំផ្លិច/practies/លំហាត់.pdf", type: "exercise" }
]
```

### បន្ថែម Icon ថ្មី

1. រូបភាព PNG ទំហំ 80x80px ឬ 100x100px
2. ដាក់ក្នុង folder `icons/`
3. ឈ្មោះ file: `01.png`, `02.png`, ... `18.png`
