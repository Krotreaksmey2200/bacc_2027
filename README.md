## 🚀 របៀបប្រើប្រាស់

1. បើក file `index.html` ក្នុង Browser
2. ជ្រើសរើសប្រធានបទដែលអ្នកចង់សិក្សា
3. អានមេរៀន និងព្យាយាមធ្វើលំហាត់អនុវត្តន៍

## 📝 របៀបកែប្រែមេរៀន

1. បើក file `js/data.js`
2. រក TOPICS array
3. កែប្រែ content នៃប្រធានបទដែលអ្នកចង់
4. បញ្ចូលមាតិកាថ្មីក្នុងទម្រង់ HTML

### ឧទាហរណ៍ការកែប្រែមេរៀន

```javascript
{
    id: 1,
    title: "កុំផ្លិច",
    icon: "🔢",
    tag: "មុខទី១",
    description: "ពិពណ៌នាថ្មី...",
    content: `
        <h3>១. និយមន័យ</h3>
        <p>មាតិកាមេរៀនថ្មី...</p>
        <div class="formula-box">
            $$x^2 + y^2 = r^2$$
        </div>
    `
}
```
