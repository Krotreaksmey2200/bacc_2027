⚙️ ការកំណត់ Firebase

Firestore Collections

សូមប្រាកដថាអ្នកបានកំណត់ Firestore Rules៖

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Collections ដែលប្រើ៖

  • users - ព័ត៌មានអ្នកប្រើប្រាស់
  • activity - ប្រវត្តិសកម្មភាព
  • allowedEmails - Email ដែលអនុញ្ញាតិ
  • blockedEmails - Email ដែលច្រានចោល
